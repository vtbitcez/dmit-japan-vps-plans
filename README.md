## 三条线路的实际差别

三条线的差别在回程路由上，不在配置单上。

**Pro（TYO.AS3.Pro）** 是旗舰线。三网回程强制走 CN2 GIA，去程按运营商分别优化：电信 CN2 GIA 直连，联通走优质线路（有资料写 AS9929，官方口径更笼统），移动 CMI 直连。这条线在日本方向的 VPS 里不常见，同质量竞品普遍定价更高。

**EB（TYO.AS3.EB）** 走 CMI/CMIN2 移动国际线路，回程强制 CMI，移动用户直连效果好，流量配额比同档 Pro 更大、带宽更高。官方和第三方对这条线的命名不统一，有写 CMI 的，有写 CMIN2 的，指的是同一类移动优化线路。

**T1（TYO.AS3.T1）** 是国际线路，没有中国大陆优化。电信联通走 NTT，移动走 CMI，不保证回国速度，偶尔绕美。它的价值在于日本原生 IP、DMIT 的硬件和 IP 池质量，以及便宜。

延迟方面，第三方测评给出的口径是：东京到大陆基础延迟 60-80ms，Pro 晚高峰基本维持在这个区间，不会出现白天 80ms、晚上 200ms 的落差。分运营商看，电信约 60-80ms（上海），联通约 50-65ms（北京），移动约 50-60ms（广州）。作为参照，洛杉矶节点平均在 150-180ms，香港 Pro 到大陆普遍在 20-50ms。这些是测评数据，实际取决于你所在城市和运营商。

香港延迟更低，但价格贵一档：香港 Pro 入门 $39.9/月，东京 Pro 入门 $21.9/月。预算有限就用东京，多出来的几十毫秒换取将近一半的价格。

## 买之前必须知道的三个限制

### 流量超了，Pro 和 T1 的后果完全不同

Pro 和 EB 超出月流量后会暂停服务，只能等下个计费周期重置，或者手动购买额外流量。做站的人要算清楚：500GB 月流量对一个日 IP 几千的站不算宽裕，超了就是停机，不是降速。

T1 超出后不停机，限速继续跑。WEE 套餐超量后限速 50Mbps，其余套餐按档位限速 100Mbps 起，具体数值以下单页为准。50Mbps 对轻量业务够用，对下载类业务就紧张了。

### 缺货是常态，尤其 Pro

Pro 系列经常处于缺货或限量状态，隔一段时间才补一批 IP。看到有货拖几天再回来看，很可能就没了。T1 的库存稳定得多，基本随时能下单。如果你的方案可以用 T1 凑合，先买 T1 跑起来，等 Pro 补货再换，比干等更实际。

### IP 被封、退款，规则都写得很细

Pro 和 EB 系列每 15 天可以申请一次免费换 IP，前提是 IP 确实被封，不是想换就换。

退款分两档：3 天内无理由全额退，条件是流量使用不超过 30GB；30 天内按剩余价值比例退。退款可以原路返回，可能扣手续费，也可以退到账户余额，免手续费。有几种情况不退：续费订单、用余额支付的订单、同一系列产品退款累计达 3 次、IP 被封。

新用户先月付跑一个周期，测完延迟和路由再决定要不要转季付锁折扣，这个顺序比一上来买年付稳。

## 这几种情况不建议买 DMIT 日本

**只想要最便宜的日本 IP。** DMIT 的溢价全在线路和 IP 池质量上，T1.WEE $36.9/年 在低价日本 VPS 里不算便宜。纯做落地、跑脚本、不需要稳定性的场景，市场上有一堆更便宜的选择。

**需要 Abema、Hulu Japan 这类完整解锁。** 第三方反馈是 Netflix 日区可用，但 Abema、Hulu Japan 需要额外配置。冲着“日本 IP 全解锁”来的，先降低预期。

**业务型用户，要求维护提前通知。** DMIT 维护不发邮件通知，偶尔出现短暂失联。对个人用户影响不大，对 SLA 有要求的业务要自己加监控和冗余。

**需要大带宽便宜流量。** T1 的 10Gbps 带宽和 128TB 流量看着很猛，但没有中国大陆优化，拿它跑国内访问是花钱买罪受。
